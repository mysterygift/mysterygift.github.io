SHOT LISTS

SHOT LISTS

Every shot, planned to the minute.

Break each scene into shots. Give each one a size, a movement, a cast and an estimated time. The schedule takes it from there.

Download latest build See the features

The short version

  • Scene by scene. Shot by shot.
  • Estimated times add up to a runtime for each day.
  • Cast set shot by shot.
  • Linked to the script, so you know it is covered.
01

Scene by scene

Pick a scene and see its shots. Create scenes by hand with a scene number and, if you like, a heading, title, INT/EXT, day or night, and location. Edit them any time. On an episodic production every scene belongs to an episode.

02

The shot table

Subject, description, size, duration, estimated minutes, movement, lens, support, notes and cast, in shot number order. Turn on Edit mode and change anything inline: click a cell, type, move on.

03

Add, duplicate, delete

Add a shot with its own shot number. Duplicate a shot and Albatross picks the next free number for the copy. Delete the ones you do not need.

04

Cast on every shot

See who is in the scene, then set who is on each shot. Reset a scene back to its cast in a click. Bookings and call sheets use this to work out who each day needs.

05

Times that add up

Give each shot an estimated shoot time. On the stripboard the minutes add up to a runtime for every shoot day, and the calendar warns you when a day runs past 10h 30min. Override the time on a single strip when you need to.

06

Linked to the script

Link each shot to the script sections it covers. A shot with no section is flagged, and so is one linked to an older script revision. That is how you know every page is covered.

The Script page →
07

Storyboard panels

Import a storyboard PDF from Athena Gallery. Albatross cuts out the panels and matches them to your shots by shot number, or by reading order. Review every match before you apply it. If a shot already has an image, choose to replace it, add to it or skip it. Or add images by hand.

Connected

Shots drive the stripboard. Their cast feeds bookings and call sheets, and their links to script sections show your coverage.
