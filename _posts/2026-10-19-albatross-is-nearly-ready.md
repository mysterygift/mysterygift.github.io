I've been putting Albatross through its paces over the last six months on real jobs from shorts and documentaries to real corporate work. My design philosophy has always been focused on real-world use cases, and I've responded directly to production needs very quickly.

It became apparent over this busy summer that a straightforward approach to collaboration was needed. Behind-the-scenes, I've been working on a postgresql layer that can be hosted on a local server which collaborators could connect to. What I found in practice was that this was not very user friendly, and if I wanted to implement this in a simpler way I'd A: be more reliant on the cloud on third party services which are expensive and frankly I don't trust.

Apple's iCloud infrastructure has become my preferred option. It's also allowed us to pivot away from expensive commercial licenses for APIs and to use the crossplatform options that Apple already supply. The only caveat here is that it means collaboration is only possible between macOS/iPhone/iPad users. Which leads us on to...

iPad and iPhone support! This initially came from conversations I've had with 1st ADs, line producers and script supervisors. It's lead to a more responsive production management software solution that responds to the needs of production. All the planning in the world cannot cover all contingencies especially in my industry. This way, I can better track what's been shot on set, how the shoot day is progressing, and facilitates quick and easy daily reports.

All this comes with the caveat - I will have to charge for Albatross. This will be a one-time payment and will cover all updates for the foreseeable future at time of writing. I'm aiming for around the £10-15 mark, because I need to cover the costs of hosting on the App Store (which is around £80.00 a year at time of writing). I believe this programme is really powerful and I want to get it into the hands of filmmakers behind projects of all scales. Distribution for Windows and Linux is to be confirmed. I currently have working builds of these apps but I need to make sure that the experience isn't compromised on these other platforms.

I've done my best to make these systems comprehensive, and in my preparation for launching on the app store in early 2027 I'll be rolling out Albatross to a number of beta testers to make sure that these features are airtight.

Lastly, I personally want to add a note about my usage of AI. I've used AI coding tools throughout the production of Albatross, in fact without it this project would have just never happened. I just did not have the resource to pool together the expertise and manpower in software design and engineering to make this happen and to not have it expressly profit-driven. I appreciate that this will invariably put some people off using Albatross, which is fair enough. From my side, my rationale is that it was worth it for the sake of giving filmmakers more tools to work with that aren't charged at what I consider unfair prices. Obviously because I'm deliberately avoiding charging a subscription model, I'm keeping running costs as low as I can which has had a hand in my decision using AI.

Either way, I'm really excited to see people using Albatross in their next project, and if you have any feature requests or suggestions please feel free to reach out to me on Instagram (@arandavies).
