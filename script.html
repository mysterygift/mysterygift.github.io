SCRIPT

Every page of the script, covered.

Import the script, split it into sections, link each section to the shots that cover it, and see at a glance what you have and what you have not.

Download latest build See the features

The short version

  • Paste it or upload it. Scenes appear.
  • Every scene split into numbered sections.
  • Sections linked to shots, gaps flagged.
  • A new draft? Compare it to the last one.
01

Script Import

Paste your script, or upload a .txt or a PDF with a text layer, up to 400 pages. There is no OCR, so a scanned PDF needs its text pasted in. Albatross finds the scenes from the INT., EXT., I/E. and INT/EXT lines. Click any scene to fix how its heading was read before anything is created.

02

Locations, tidied

Every location in the import is listed up front. Merge the variants before you import so you do not end up with duplicate locations.

03

Script Sections

Each scene is split into numbered sections, 12.1, 12.2 and so on, and you read them in the script itself. Click or drag across the script to set a section's range. Add your own, or mark one as cut and it drops out of coverage, scheduling and sides. Page counts from a text file are estimates.

04

Know what is covered

Every section carries a status Albatross works out for itself. No coverage: no shot is linked. Covered: shots are linked. Scheduled: every linked shot is on the stripboard. Shot: every linked shot has a printed take. Cut: you marked it. Filter by status, with a count on each.

05

Match sections to shots

On the Shot List, open Sections on any shot. Click or drag across the script, or tick sections in the list, then save. A shot with no sections shows No coverage, and after a new script revision, linked shots can show Needs review.

06

A new draft, no panic

Give each import a version label and a revision colour. Tick Link to previous script version for a revised draft and Albatross compares the two: matched, changed, removed and new sections. Apply safe shot link remaps to carry your links across. Links you made by hand are never moved for you.

07

What each shoot day needs

In a Calendar day summary, Albatross lists the sections that day needs, worked out from the shots on the stripboard. Sections reached through linked shots are Included. A scene with no linked sections falls back to the full scene. You see the estimated eighths for the day.

08

Daily sides, as a shooting script

Open the Sides Builder from a Calendar day. Filter by unit, scene, character, location or episode, or to linked-shot sections only, then tick what goes in. Validation lists problems, and blocking ones stop the export. The PDF is laid out like a shooting script, with the scene number either side of each heading, and is filed in Documents.

Connected

Shots link to sections. The stripboard decides which sections each shoot day needs, and the sides are built from them. Tag the same script for departments in Script Breakdown.
