SCRIPT

Every page of the script, covered.

Import the script, split it into sections, link each section to the shots that cover it, and see at a glance what you have and what you have not.

Download latest build See the features

The short version

  • Paste it or upload it. Scenes appear.
  • Every scene split into sections.
  • Sections linked to shots, gaps flagged.
  • A new draft? Compare it to the last one.
01

Script Import

Paste your script, or upload a .txt or text-based PDF. Albatross finds the scenes from the INT., EXT., I/E. and INT/EXT lines. Look over what it found and fix any scene before anything is created.

02

Locations, tidied

Every location in the import is listed up front. Merge the variants before you import so you do not end up with duplicate locations.

03

Script Sections

Each scene is split into sections with page and eighth ranges, eight eighths to a page. Albatross generates them and marks the ranges as estimates. Add your own, adjust the boundaries, and mark each one Unplanned, Planned, Scheduled, Shot or Omitted. Read the script text beside them.

04

Match sections to shots

On the Shot List, link each shot to the sections it covers. Pick from the scene's sections and read the script text as you choose.

05

See your coverage

For each scene: sections covered, coverage percentage, linked and unlinked shots, and uncovered sections. A section with no shots is flagged. So is a shot with no section, and a scene where the shots cover less than the full page length.

06

A new draft, no panic

Label each version and give it a revision colour. Import a revised script and Albatross links it to the previous one. Reconcile compares the two: matched, changed, removed and added sections. Safe shot links carry over when you apply them. Links you made by hand are never moved for you.

07

What each shoot day needs

Albatross works out which sections each shoot day needs from the shots on the stripboard. Sections reached through linked shots are Included. A scene with no linked sections falls back to the full scene. You see the estimated eighths for the day.

08

Daily sides

Build the day's sides from those sections. Filter by unit, episode, scene, character or location, and tick what goes in. Checks warn you if a scheduled section is missing from the sides, or a selected one is not scheduled. Export a PDF, filed in Documents.

Connected

Shots link to sections. The stripboard decides which sections each shoot day needs, and the sides are built from them.
